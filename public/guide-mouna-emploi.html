1. نظرة عامة على فكرة المنصة وآلية عملها (Business Logic)

صُممت منصة منى تشغيل (Mouna Emploi) لتعمل كوكالة تشغيل مؤقت (Intérim) ذكية ومؤمنة بنسبة 100% في المغرب، وتربط في الوقت الفعلي بين ثلاثة أطراف رئيسية:

  1. المترشح (Candidat Intérimaire) : ينشئ ملفه المهني، يحدد مهاراته التقنية ومدينته وأجره اليومي بالدرهم، ويترشح لمهام العمل بنقرة واحدة.
  2. المشغل / الشركة (Recruteur Entreprise) : ينشر عروض العمل المؤقتة، يفلتر الكفاءات حسب المهارات التقنية والمدينة والتفرغ، ويتابع الترشيحات.
  3. مدير المنصة / الوكالة (Administrateur Mouna Emploi) : يمتلك الصلاحية الحصرية للوصول إلى "خزنة البيانات الشخصية السرية (Coffre-Fort PII)" للربط القانوني والتعاقدي بين الشركات والمترشحين.

مبدأ السرية وحماية عمولة الوكالة (Anonymisation Anti-PII)

  • رموز مستعارة فقط (Alias Codes) : يتعامل المترشحون والمشغلون داخل المنصة عبر رموز مستعارة مثل CAND-8412 للمترشح و REC-9012 للمشغل دون كشف هويتهم الحقيقية لبعضهم البعض.
  • عزل البيانات الشخصية في خزنة الإدارة (/user_pii) : الأسماء القانونية الكاملة، أرقام الهاتف، البريد الإلكتروني، ورقم البطاقة الوطنية أو التعريف الموحد للشركة (CIN / ICE) تُحفظ في جدول معزول في قاعدة البيانات لا يمكن لأي مستخدم عادي قراءته، ويظهر فقط لمدير المنصة (Admin).
  • الفلترة الذكية في المحادثة (sanitizePublicText) : إذا حاول مترشح أو مشغل كتابة رقم هاتفه أو بريده الإلكتروني داخل الدردشة المباشرة أو في وصف العرض، يقوم النظام تلقائياً بإخفائه واستبداله بعبارة [TÉLÉPHONE MASQUÉ PAR MOUNA EMPLOI].

2. الهيكلة البرمجية والتقنيات المستخدمة (Architecture Technique)

أ. الواجهة الأمامية (Frontend)

  • React 19 + TypeScript + Vite : واجهة تفاعلية فائقة السرعة ومتجاوبة بالكامل مع الهواتف الذكية والحواسيب.
  • Tailwind CSS + تصميم ثلاثي الأبعاد متحرك (3D Relief Design) : خلفية بيضاء نقية (#FFFFFF)، بطاقات وإطارات بنية ثلاثية الأبعاد متحركة (.card-3d-brown)، أزرار بنية بنص أبيض بارز (.btn-3d-brown)، وزر واتساب أخضر ثلاثي الأبعاد (.btn-3d-whatsapp).
  • ثنائية اللغة (Bilingue FR / AR) : دعم فوري للغتين العربية (RTL بخط Cairo) والفرنسية (LTR بخط Plus Jakarta Sans).
  • Recharts : لعرض الرسوم البيانية التحليلية لنشاط التوظيف والقطاعات.

ب. الخادم الخلفي (Backend — server.ts)

  • Express.js (Node.js) يعمل على المنفذ 3000.
  • البث الفوري للأحداث (Server-Sent Events - SSE) : عبر المسار /api/realtime/stream و /api/realtime/notify لإرسال إشعارات فورية (Push Notifications) لجميع المتصلين في الوقت الفعلي وتحديث عداد المتصلين.
  • بوابة التحقق من الاشتراكات (/api/billing/checkout) : للتحقق من بيانات البطاقة البنكية (CMI / Visa) وتفعيل الباقات الشهرية.

ج. قاعدة البيانات والمصادقة (Firebase)

  • Firebase Authentication : تسجيل دخول آمن ومباشر عبر حساب Google.
  • Cloud Firestore : قاعدة بيانات فورية (Real-time onSnapshot) محمية بقواعد أمان صارمة (firestore.rules).

3. خارطة ملفات المشروع وكيفية عمل كل ملف

اسم الملف وظيفته الأساسية متى تحتاج لتعديله؟
src/i18n.ts يضم جميع النصوص المترجمة (عربي/فرنسي)، قائمة المدن المغربية (MOROCCAN_CITIES)، المهارات التقنية (MOROCCAN_SKILLS)، القطاعات (SECTORS)، وجملة استفسار الواتساب. عند إضافة مدن أو مهارات جديدة، أو تعديل أي نص أو عنوان أو رسالة الواتساب.
src/App.tsx المكون الرئيسي للمنصة: يحتوي على جميع الشاشات الـ 8، زر الواتساب، حساب نسبة التوافق، وإدارة الحالة الفورية مع Firestore. عند تعديل واجهة المستخدم، تغيير رقم الواتساب، أو تعديل منطق العرض.
src/seedData.ts يحتوي على البيانات المغربية التجريبية التي تُضخ في قاعدة البيانات عند الضغط على زر "تحميل بيانات تجريبية مغربية". لتغيير العروض أو الملفات الافتراضية الأولية.
src/index.css يحتوي على تصميم البطاقات والأزرار ثلاثية الأبعاد وألوان المنصة وإعدادات الهواتف. عند الرغبة في تغيير الألوان أو تأثيرات البروز ثلاثي الأبعاد.
src/firebase.ts إعداد الاتصال بـ Firebase ودالة فلترة وإخفاء أرقام الهاتف والإيميلات (sanitizePublicText). عند تعديل قواعد الفلترة التلقائية للبيانات الشخصية في الشات.
src/types.ts تعريفات هياكل البيانات (Interfaces) لجميع الجداول. عند إضافة حقل جديد لأي جدول.
server.ts خادم Express.js للبث الحي للإشعارات ومعالجة الدفع. عند ربط بوابة دفع بنكية خارجية.
firestore.rules قواعد الحماية الأمنية لقاعدة بيانات Firestore. عند إضافة صلاحيات جديدة أو تغيير بريد المدير العام.

4. شرح هيكلة قاعدة البيانات (Collections Firestore)

  1. public_profiles/{userId} (الملفات العامة المجهولة) : تضم الرمز المستعار (aliasCode)، الدور (candidate | recruiter | admin)، المسمى الوظيفي بالعربية والفرنسية، المدينة، سنوات الخبرة، التفرغ، المهارات، الأجر اليومي بالدرهم، وحالة الاشتراك.
  2. user_pii/{userId} (خزنة البيانات السرية المعزولة) : تضم الاسم الكامل القانوني (fullName)، البريد الإلكتروني (email)، رقم الهاتف (phone)، رقم البطاقة الوطنية أو التعريف الضريبي (cinOrIce)، اسم الشركة (companyLegalName)، والعنوان الدقيق (exactAddress). لا يقرأه إلا صاحب الحساب أو المدير العام.
  3. jobs/{jobId} (عروض ومهام العمل المؤقت) : تضم عنوان العرض بالفرنسية والعربية، القطاع، المدينة، نوع العقد، المدة بالأسابيع، الراتب الشهري بالدرهم (salaryMad)، والمهارات المطلوبة.
  4. applications/{applicationId} (طلبات الترشيح) : تربط بين المترشح والعرض والمشغل، وتحسب تلقائياً نسبة التوافق المئوية (matchScore)، وتتابع حالة الطلب.
  5. chats/{threadId} ورسائلها messages : تفتح محادثة آمنة ومجهولة الهوية بين المشغل والمترشح بمجرد الترشح للوظيفة.
  6. notifications/{notificationId} (الإشعارات الفورية) : تحفظ تنبيهات كل مستخدم وتعرضها في درج الإشعارات العلوي.
  7. subscriptions/{subscriptionId} (سجل الاشتراكات الشهرية) : يوثق اشتراكات الباقات الشهرية (99 درهم للمترشح، 490 درهم للمشغل، 1490 درهم للمجموعات الكبرى).

6. كيفية تحديث المعطيات والبيانات (من الألف إلى الياء)

أولاً: التحديث المباشر من واجهة المنصة (بدون تعديل الكود)

  • نشر عرض عمل جديد : من الزر العلوي "نشر عرض عمل جديد" ← املأ بيانات العرض باللغتين وحدد المهارات والراتب ← يُنشر العرض فوراً لجميع المتصلين.
  • تعديل الملف المهني والبيانات السرية (PII) : من تبويب "ملفي والخصوصية" ← عدّل مهاراتك وأجرك اليومي في البطاقة الأولى، وعدّل اسمك القانوني ورقم هاتفك وبطاقتك الوطنية CIN / ICE في البطاقة الثانية ← اضغط "حفظ التغييرات".
  • إدارة حالة الترشيحات : من تبويب "تتبع الترشيحات" ← اضغط على أزرار تغيير الحالة (مقبول أولياً، مقابلة عمل، تم التعاقد، مرفوض) ليتم التحديث فوراً في قاعدة البيانات مع إرسال إشعار حي للمترشح.
